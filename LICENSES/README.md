# LICENSES/

本目录保存**不再适用于当前版本、但仍需保留原文**的许可材料。

This directory holds license material that no longer governs the current version but must still be
preserved verbatim.

- `MIT-legacy.txt` — 本项目在 `mit-final`（`fb57ddca483f3bfe816a3ca8e59d6d5208ef7c64`）及之前以 MIT 发布时的授权原文。
  该授权不因后续切换到 AGPL-3.0-only 而撤销。

当前生效的第三方许可（含 `@fontsource/noto-sans-jp` 与 `@fontsource/jetbrains-mono` 的 SIL Open Font
License 1.1 正文）统一收录在仓库根的 [`THIRD-PARTY-NOTICES.md`](../THIRD-PARTY-NOTICES.md)，由
`npm run notices` 生成。

The third-party licenses currently in effect — including the SIL Open Font License 1.1 texts for the
bundled webfonts — are consolidated in [`THIRD-PARTY-NOTICES.md`](../THIRD-PARTY-NOTICES.md), generated
by `npm run notices`.
